💥 Flames – Relationship Destiny Game

A fun and interactive FLAMES game web app that calculates the relationship result between two names using the classic FLAMES algorithm. Users can enter two names and instantly reveal whether they’re Friends, Lovers, Affectionate, Married, Enemies, or Siblings.

FLAMES is a popular paper-and-pencil game used by kids and teens to playfully predict relationship status. It’s based on counting characters and eliminating letters from the word “FLAMES” to arrive at a result.

🧠 What is FLAMES?

FLAMES is an acronym representing possible relationship outcomes:

F – Friends

L – Love

A – Affection

M – Marriage

E – Enemy

S – Sibling (or Sister)

The game works by removing shared letters from two names, counting the remaining characters, and using that count to eliminate letters in “FLAMES” in a circular fashion until only one remains. The final remaining letter is the result.
